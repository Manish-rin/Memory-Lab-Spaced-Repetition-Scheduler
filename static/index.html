Mathematical & Cognitive Architecture

    

      
1. Dataset Foundation: Trained on 1,081,771 cleaned review logs across 4,167 distinct students from the MaiMemo open-source dataset (Ye et al., ACM SIGKDD 2022).

      
2. Exact 17 Engineered Features (src/features.py): d, word_len, i, history_len, total_recalls, total_lapses, historical_accuracy, lapse_ratio, last_outcome, recent_3_acc, last_interval, mean_interval, max_interval, total_study_span, delta_t, log_delta_t, and elapsed_to_last_ratio.

      
3. Monotonic Decay Guarantee (monotonic_cst = -1): Enforces strictly non-increasing recall probabilities with respect to elapsed time (delta_t, log_delta_t, elapsed_to_last_ratio) and word difficulty (d), eliminating observational selection bias.

      
4. 3-Fold Isotonic Calibration: Wraps the gradient boosted trees in CalibratedClassifierCV(method='isotonic', cv=3) so predicted probabilities match empirical retention frequencies for accurate threshold scheduling.
